# Get Next Line · Earlier implementation

An earlier line-reader implementation and its test fixtures, preserved from `Lvl01/gnl` when the Common Core hub was reorganized.

This is supporting practice. The main project and current standalone documentation are in [get-next-line](https://github.com/Rspinelli93/get-next-line).

## Contents

- `get_next_line.c`, `get_next_line_utils.c`, and `get_next_line.h`: line reading and buffer helpers.
- `tests/files/`: newline, empty-file, length, and other fixtures.
- `tests/test.c`, `tests/test.sh`, and `tests/val_test.sh`: the original test material; inspect each script’s relative paths before running.
