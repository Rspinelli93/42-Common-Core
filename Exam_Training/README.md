# Exam training

Independent practice exercises for 42 exam preparation. These files are study material, not official exam submissions or a record of passed exams.

| Folder | Practice topics |
| --- | --- |
| [Exam02](Exam02/) | Strings, numbers, arrays, and lists |
| [Exam03](Exam03/) | Line reading, filtering, formatted output, and combinatorial problems |
| [Exam04](Exam04/) | Pipes, small shells, parsing, and expression evaluation |
| [Exam05](Exam05/) | C++ value types, bags/sets, and C exercises |

## Working with an exercise

Read the selected source and any supplied main program. Compile one exercise at a time with a C or C++ compiler; there is no shared Makefile for the folder. Some files contain partial solutions or functions that need a test driver.

Rebuild from source instead of relying on checked-in executables, which may target a different system. The directory names reflect this practice collection and may not match every version of the exam subjects.
